# Application

CQRS (Command Query Responsibility Segregation) vrstva mezi prezentací a doménou. Balíčky `bus/` (middleware chain a dispatch), `command/` (write operace), `query/` (read operace), `event/` (side-effects). Závisí pouze na `domain/`.
