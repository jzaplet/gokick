# ADRs

**Architecture Decision Records** zachycují klíčová, zafixovaná rozhodnutí — produktová
i architektonická — na kterých projekt staví. Jeden soubor = jedno rozhodnutí.

Pravidla:

- Číslování `NNNN-kebab-title.md` (`0000`, `0001`, …), nikdy nepřečíslovávat.
- Jednou přijatý ADR se **nemění**; když rozhodnutí padne, vznikne nový ADR, který ten
  starý označí jako *Superseded by ADR-XXXX*.
- ADR je krátký — Context → Decision → Consequences.
- Roadmap fáze na ADR odkazují (*„Adresuje ADR"*); viz [Roadmap](/roadmap).

**Statusy** (lifecycle jednoho rozhodnutí):

- **Proposed** — navržené, ještě nepřijaté (výchozí stav nového ADR).
- **Accepted** — přijaté a platné; fáze na něm staví.
- **Superseded** — nahrazené pozdějším ADR (odkaz *Superseded by ADR-XXXX*).
- **Deprecated** — už neplatí, ale bez náhrady.

Šablona a první záznam: [ADR-0000 — Project scope](/adrs/0000-adr-project-scope).
