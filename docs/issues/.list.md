# Issues

**Issue** je konkrétní kus práce s vlastním stavem (🔴 nezačato · 🟡 probíhá · ✅ hotovo).
Issues vznikají z [Briefs](/briefs) a roadmap fáze je referencují.

Kategorie:

- [Features](/issues/features) — nová funkčnost
- [Bugs](/issues/bugs) — defekty (register `D01–DNN`)
- [Chores](/issues/chores) — údržba, refaktory, závislosti, infrastruktura

Pravidla: číslování `NNNN-kebab-title.md` v rámci kategorie; název říká *co*, ne *proč*
(proč je v briefu).
